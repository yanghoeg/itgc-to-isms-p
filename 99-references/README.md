> 최종 확인: 2026-07-26. 법령은 적용 시점의 시행본을 다시 확인한다.

- **회계감사기준서 240 / 265 / 315 / 330 / 500 / 530** — 한국공인회계사회
- **「내부회계관리제도 모범규준」** — 한국회계기준원

## 인용 원칙

- 1차 자료가 2차 자료와 충돌하면 1차 자료 우선
- KISA 안내서·회계감사기준서는 출처 링크 + 작성자의 말로 요약
- 법령을 인용할 때는 시행일·조문·공식 링크·확인일을 표기
- 2차 자료는 보조 참조로만 사용
