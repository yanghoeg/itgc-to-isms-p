# 2.2.3 보안 서약

> **기준 판본**: [KISA ISMS-P 인증기준 안내서(2023.11.23)](https://www.isms-p.or.kr/ntcn/rcsrm/selectGnrlRcsrmList.do).
> **관련 법령**: 2026-07-26 기준.
> **내용 구분**: §1은 KISA 안내서 및 법령의 요약, §3~§4은 작성자의 실무 경험에 기반한다.

## 1. ISMS-P 기준 요약

### 인증기준
정보자산에 접근하는 임직원·임시직원·외부자가 정책·법규·비밀유지 의무를 알도록 입사·접근권한 부여·퇴직 단계에 적절한 서약을 받고 안전하게 보관하여야 한다.

### 주요 확인사항 (KISA 안내서)
1. 신규 인력에게 보호책임이 명시된 서약을 받는가?
2. 외부자에게 비밀유지·보호책임 서약을 받는가?
3. 퇴직 시 별도의 비밀유지 서약을 받는가?
4. 서약서를 안전하고 검색 가능하게 관리하는가?

### 결함사례 (KISA 안내서)
- 신규 입사자 일부의 보안서약이 누락됨
- 시스템에 직접 접근하는 외주인력에게 서약을 받지 않음
- 서약서 원본을 비인가자가 접근 가능한 곳에 방치함
- 개인정보취급자 서약에 개인정보보호 책임이 빠짐

## 2. ITGC 매핑

| 항목 | 값 |
|---|---|
| 분류 | 간접 (2-indirect) |
| ITGC 영역 | ELC/personnel |
| 보조 영역 | 외부자·퇴직관리 |

## 3. IT감사에서는 이렇게

### 3-A. 한국 비금융 ITGC 실무 적용

보안서약은 통제환경 증거지만 계정·권한·로그 통제를 대체하지 않는다. 고위험 IT 인력과 외부 개발·운영자의 적용 여부를 중심으로 확인한다.

| ISMS-P 요구사항 | ITGC 확인 절차 | 모집단 | 표본 |
|---|---|---|---|
| 적용 대상 | HR·외부자 명단과 서약 대상 대조 | 신규·퇴직·외부자 | 표본 |
| 내용 | 비밀유지·정보보호·퇴직 후 의무 포함 여부 확인 | 사용 양식 | 전수 |
| 보관 | 접근제한·검색·보존 방식 확인 | 서약서 저장소 | 워크스루 |

### 3-B. ISMS-P 추가 요구사항 중 일반 ITGC 범위 밖

전 임직원과 개인정보취급자의 법적 서약 내용은 인사·법무·개인정보보호 영역의 비중이 크다.

## 4. Q&A

### Q1. 근로계약서에 비밀유지 조항이 있으면 별도 서약이 필요 없는가?
A. 적용 대상·시점과 필요한 보호책임이 모두 포함되는지 확인해야 한다. 대체 문서가 같은 통제 목적을 충족하면 형식보다 내용과 증적을 평가한다.
