# 2.6.5 무선 네트워크 접근

> **기준 판본**: [KISA ISMS-P 인증기준 안내서(2023.11.23)](https://www.isms-p.or.kr/ntcn/rcsrm/selectGnrlRcsrmList.do). 관련 법령은 2026-07-26 현재 시행본을 기준으로 확인했다.
> **내용 구분**: §1은 KISA 안내서·법령의 요약이고, §3~§4의 한국 비금융 ITGC 범위와 판단은 작성자의 실무 경험에 기반한다.

## 1. ISMS-P 기준 요약

### 인증기준
무선 네트워크를 사용하는 경우 사용자 인증, 송수신 데이터 암호화, AP 통제 등 보호대책을 적용하여야 한다. 또한 애드혹 접속과 비인가 AP 등 비인가 무선 네트워크 접속에 대한 보호대책을 수립·이행하여야 한다.

### 주요 확인사항 (KISA 안내서)
1. 업무용 무선 AP와 네트워크 구간에 인증·송수신 데이터 암호화 등 보호대책을 적용하고 있는가?
2. 인가된 임직원만 무선 네트워크를 사용하도록 신청·해지 절차를 수립·이행하고 있는가?
3. 애드혹 접속과 비인가 AP의 탐지·차단 등 비인가 무선 네트워크 보호대책을 수립·이행하고 있는가?

### 관련 법규
- 개인정보 보호법 제29조 (안전조치의무)
- 개인정보의 안전성 확보조치 기준 제6조 (접근통제)

### 핵심 통제 (KISA 안내서)
- 무선 AP 목록과 관리자 접근 통제
- WPA2-Enterprise·WPA3-Enterprise 등 사용자 인증과 송수신 암호화
- 사용자·단말 등록 및 사용권한 신청·해지
- 외부인용 무선망과 임직원용 무선망 분리
- WIPS 또는 정기 점검을 통한 비인가 AP 탐지

### 결함사례 (KISA 안내서)
- **사례 1**: 외부인용 무선망과 내부 무선망을 분리하지 않아 외부인이 내부망에 접근할 수 있음
- **사례 2**: 송수신 암호화를 안전하지 않은 방식으로 설정함
- **사례 3**: 업무용 무선 AP에 기본 관리자 비밀번호를 사용하거나 관리자 접근통제를 적용하지 않음

## 2. ITGC 매핑

| 항목 | 값 |
|---|---|
| 분류 | 직접 (1-direct) — 단, ITGC 포함 여부는 재무보고 위험에 따라 판단 |
| ITGC 영역 | APD와 연관되나 주된 담당 영역은 네트워크 보안 |
| 부영역 | — |
| 보조 영역 | 2.6.1 (네트워크 접근 — 무선 경유 내부 접근 시) |

## 3. IT감사에서는 이렇게

### 3-A. 한국 비금융 ITGC 실무 적용

**무선랜 보안은 일반적으로 네트워크 보안 영역에서 검토한다.** 다만 무선 네트워크가 재무보고 시스템으로 이어지는 주요 접근 경로라면, 해당 경로의 인증·분리·접근통제를 ITGC 범위에 포함할 수 있다.

| ISMS-P 요구사항 | 주된 검증 위치 | ITGC 연계 |
|---|---|---|
| 무선 인증·암호화 | **정보보안팀** 네트워크 보안 점검·취약점 진단 | 재무보고 시스템의 주요 접근 경로이면 관련 설정 확인 |
| 비인가 AP 탐지·차단 | **WIPS·보안관제(SOC)** | 일반적으로 ITGC 범위 밖 |
| 외부인용 무선망 분리 | **네트워크 구성 점검** | 감사 범위 내 시스템으로의 접근 경로가 있으면 2.6.1과 연계 |

**ITGC와의 주된 접점**: 무선을 통해 운영 서버·재무시스템에 접근 가능한 경로가 있으면, 그 접근은 2.6.1(네트워크 접근)과 연계하여 본다. 무선 매체 자체의 보안은 일반적으로 정보보호 범위지만, 취약한 인증·암호화가 감사 범위 내 시스템의 비인가 접근 위험으로 직접 이어지면 관련 통제를 제외할 수 없다.

따라서 ISMS-P 인증심사에서는 독립 기준으로 평가하고, ITGC에서는 재무보고 시스템과의 연결성을 기준으로 별도 절차 또는 2.6.1 교차참조 여부를 정한다.

### 3-B. ISMS-P 추가 요구사항 중 일반 ITGC 범위 밖

| ISMS-P 요구사항 | 절차 | 주된 담당 영역 |
|---|---|---|
| 무선 인증·암호화 강도 | WPA2-Enterprise·AES 적용 확인 | **네트워크 보안 / 모의해킹** |
| 비인가 AP 탐지 | WIPS 운영·탐지 이력 | **보안관제(SOC)** |
| 게스트망 분리 | VLAN·방화벽 구성 | **네트워크 구성 점검** |

## 4. Q&A

### Q1. 비금융 ITGC에서 무선 네트워크를 보나?

A. **일반적으로 네트워크 보안 영역이지만, 재무보고 시스템의 접근 경로라면 ITGC와 연계한다.**
- 무선랜 자체의 인증·암호화·비인가 AP 통제는 보통 정보보호 감사조서에서 다룸
- 무선망이 감사 범위 내 시스템으로 연결되면 2.6.1의 접근 경로 검증에 포함
- 별도 감사조서가 필요하지 않은 경우에도 기존 조서에 범위 판단과 교차참조를 명시

### Q2. 무선이 ITGC와 닿는 주된 지점은?

A. **주된 접점은 무선을 통한 내부망·서버 접근 *경로*의 통제다.**
- **접근통제(2.6.1)** 와 연계하여 "무선 → 내부망 → 재무서버" 경로가 적절히 인증·차단·분리되는지 확인
- 무선 인증·암호화의 취약성이 해당 경로의 비인가 접근 위험에 직접 영향을 주면 관련 설정도 함께 검토
