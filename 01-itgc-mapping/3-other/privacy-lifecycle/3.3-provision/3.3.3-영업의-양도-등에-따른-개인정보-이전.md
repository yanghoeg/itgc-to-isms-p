# 3.3.3 영업의 양도 등에 따른 개인정보 이전

> **기준 판본**: [KISA ISMS-P 인증기준 안내서(2023.11.23)](https://www.isms-p.or.kr/ntcn/rcsrm/selectGnrlRcsrmList.do).
> **관련 법령**: 2026-07-26 기준.
> **내용 구분**: §1은 KISA 안내서 및 법령의 요약, §3~§4은 작성자의 실무 경험에 기반한다.

## 1. ISMS-P 기준 요약

### 인증기준
영업의 양도·합병 등으로 개인정보를 이전할 때 이전 사실, 받는 자, 거부 방법 등을 미리 알리고, 영업양수자는 통지 여부를 확인해 필요한 경우 지체 없이 알리며 원래 목적 범위에서만 처리하여야 한다.

### 주요 확인사항 (KISA 안내서)
1. 영업양도자는 이전 전에 법정 사항을 통지하는가?
2. 영업양수자는 종전 통지가 없었다면 지체 없이 통지하는가?
3. 이전받은 개인정보를 당초 목적 범위에서만 이용하는가?

### 결함사례 (KISA 안내서)
- 양도자가 통지하지 않았는데 양수자도 이전 사실을 알리지 않음
- 이전 거부 방법이나 절차를 제공하지 않음
- 이전받은 개인정보를 당초 목적과 다른 마케팅에 사용함

## 3. IT감사에서는 이렇게

### 3-A. 한국 비금융 ITGC 실무 적용

통지의 법적 적정성은 일반 ITGC 밖이지만, 이전 대상·제외 대상·건수의 완전성·정확성과 안전한 이관은 데이터 마이그레이션 통제에 연결된다.

| ISMS-P 요구사항 | IT감사 연계 절차 | 모집단 | 표본 |
|---|---|---|---|
| 이전 범위 | 승인된 데이터 범위와 실제 테이블·파일 대사 | 이전 객체 | 전수 또는 표본 |
| 거부 반영 | 거부 접수와 이관 제외 로직 재수행 | 거부자·이관자 | 표본 |
| 안전한 이관 | 암호화, 권한, 건수 대사, 원본·임시파일 처리 확인 | 이관 실행 | 표본 |

### 3-B. ISMS-P 추가 요구사항 중 일반 ITGC 범위 밖

영업 양도 등의 성립 여부, 통지 시점·내용·방법, 양수자의 목적 범위 판단은 개인정보·법무 준거성 영역이다.

## 4. Q&A

### Q1. 합병으로 법인이 소멸하면 통지를 생략할 수 있는가?
A. 합병 형태만으로 생략을 단정할 수 없다. 개인정보 이전 주체와 법 제27조 적용 여부를 법무 검토하고, 양도자·양수자의 통지 이행을 증빙해야 한다.
